Luz 0.2.1 usa la página «Acerca de» compartida de Nodalia, igual que el resto de apps, sin pestañas de Colaboradores ni Modelos.

*Luz 0.2.1 uses the shared Nodalia About page, like the rest of the apps, without Contributors or Models tabs.*

## Español

### Correcciones
- **Acerca de:** ahora es la página común de Nodalia (icono, nombre, versión, enlaces y pie). Se quitan las pestañas de Colaboradores y Modelos y las listas que se compilaban dentro del programa.

## English

### Fixes
- **About:** it is now the common Nodalia page (icon, name, version, links and footer). The Contributors and Models tabs and the lists compiled into the binary are gone.
